# Breast Risk Hub — версия 0.5.0

Локальный исследовательский прототип единой формы для:

- PREDICT Breast v3.2;
- CRIB premenopausal (TEXT/SOFT, DRFI model);
- CRIB postmenopausal (BIG 1-98).

## Что исправлено в 0.3.0

Расчет PREDICT полностью заменен на реализацию официального алгоритма
v3.2 без подбора констант по отдельному пациенту.

Используются:

- точные коэффициенты `coefficients_v3.csv`;
- фиксированный расчетный год 2017;
- baseline adjustment 0,7 при ER+ и 0,55 при ER−;
- baseline adjustment −0,062 для прочей смертности;
- временно-зависимый эффект HER2;
- конкурирующие риски смерти;
- влияние химиотерапии и лучевой терапии на прочую смертность;
- последовательное добавление терапии в порядке официального сайта.

Добавлено:

- поле «Только микрометастазы» при одном положительном лимфоузле;
- преобразование `1 узел + только микрометастазы` в 0,5 узла для PREDICT;
- выбор гормонотерапии: нет / 5 лет / 10 лет;
- дополнительный эффект 10-летней гормонотерапии в годы 11–15;
- блок, показывающий, как введенные данные интерпретированы PREDICT;
- два автоматических контрольных теста по предоставленным скриншотам.

## Контрольные случаи

### Случай 1

30 лет, скрининг, 30 мм, grade 2, 4 узла, ER+, PgR−,
HER2−, Ki-67+, гормонотерапия 5 лет и химиотерапия третьего
поколения:

- только операция: 86%;
- гормонотерапия: +4,2%, итог 90%;
- химиотерапия: +3,3%, итог 93%.

### Случай 2

55 лет, постменопауза, скрининг, 15 мм, grade 1, один
положительный узел без указания «только микрометастазы», ER+,
PgR+, HER2−, Ki-67+, лучевая терапия с дозой на сердце 0 Gy,
гормонотерапия 5 лет и бисфосфонаты:

- только операция: 98%;
- лучевая терапия: +0,2%, итог 98%;
- гормонотерапия: +0,4%, итог 98%;
- бисфосфонаты: +0,1%, итог 99%.

## Статус

Несмотря на совпадение двух контрольных случаев, версия остается
исследовательской. Перед клиническим использованием необходимо проверить
широкую матрицу случаев: ER−, HER2+, разные возраста, размеры, число
лимфоузлов, курение, неизвестные значения, 10-летнюю гормонотерапию и
разные горизонты прогноза.

## Запуск на macOS

Требуется Python 3.11 или новее.

1. Распакуйте архив.
2. Правой кнопкой нажмите `Start.command`.
3. Выберите «Открыть».
4. Браузер откроет `http://127.0.0.1:8000`.

Для остановки нажмите `Control + C` в Terminal.

## Windows

Дважды нажмите `start_windows.bat`.

## Linux

```bash
chmod +x start_linux.sh
./start_linux.sh
```

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
```

## Новое в 0.4.0 — расширенная интерпретация CRIB postmenopausal

Для постменопаузальной модели теперь выводятся:

- группа риска:
  - низкий: CRIB <0,66;
  - промежуточный (умеренный): CRIB 0,66–1,53;
  - высокий: CRIB >1,53;
- полная таблица опубликованной 5-летней DFS для четырех вариантов
  эндокринотерапии BIG 1-98;
- подсветка строки, соответствующей рассчитанной группе риска;
- подсветка максимального опубликованного показателя DFS в каждой строке;
- отдельный блок с вариантом терапии, которому соответствует наибольшая
  наблюдаемая 5-летняя DFS в выбранной группе.

Таблица воспроизводит значения оригинального CRIB:

| Группа | Летрозол | Летрозол → тамоксифен | Тамоксифен → летрозол | Тамоксифен |
|---|---:|---:|---:|---:|
| Низкий риск | 96% | 94% | 93% | 94% |
| Промежуточный риск | 90% | 91% | 93% | 86% |
| Высокий риск | 80% | 76% | 74% | 69% |

Важно: это групповые оценки из BIG 1-98, а не индивидуальная вероятность
ответа на лечение и не автоматическая лечебная рекомендация.
